# Карточка-био Qcoldu · HTML5 + CSS + JavaScript

Одностраничная персональная визитка-карточка без фреймворков, сборщиков и внешних
библиотек. Открывается двойным кликом по `index.html` или с любого статического хостинга.

**Живая версия:** https://danilsoroka2013-ux.github.io/mybio/

## Возможности

- **Две темы** — тёмная и светлая, переключатель в правом верхнем углу, выбор
  запоминается в `localStorage`, по умолчанию учитывается `prefers-color-scheme`.
- **Вкладки** — «Обо мне», «Навыки», «Контакты». Работают мышью и клавиатурой
  (`←` / `→` / `Home` / `End`), панели не «прыгают» по высоте.
- **Эффект печатной машинки** в подзаголовке.
- **Живые счётчики** опыта и проектов с плавной анимацией при появлении.
- **Анимированные полосы навыков.**
- **Копирование контактов** в буфер обмена (с фолбэком для `file://`).
- **Кнопка «Поделиться»** через Web Share API, с фолбэком на копирование ссылки.
- **Местное время** (часовой пояс Хабаровска, UTC+10) обновляется само.
- **Адаптивность** от 320 px, поддержка `prefers-reduced-motion`, видимый фокус,
  семантика и ARIA для скринридеров.
- **Пасхалка**: нажмите клавишу `C` (кириллическую `С` тоже понимает).
- Запасной аватар-монограмма, если картинка не загрузилась; отдельные стили для печати.

## Структура

```
.
├── index.html          разметка карточки
├── css/style.css       токены тем, компоненты, адаптив, анимации
├── js/app.js           вся логика (IIFE, без зависимостей)
└── assets/
    ├── avatar.jpg      аватар 512×512
    └── favicon.svg     иконка вкладки
```

## Как запустить

Просто откройте `index.html` в браузере. Для проверки по HTTP (нужно для буфера обмена
на некоторых браузерах):

```bash
python3 -m http.server 8080
# затем http://localhost:8080
```

## Как сделать карточку своей

1. **Тексты** — правьте `index.html`: имя, роль, описание, навыки, контакты.
   Статистика задаётся атрибутами `data-count-to`, `data-suffix` и `data-decimals`
   (для дробных значений вроде `1.5` → «1,5»).
2. **Фото** — замените `assets/avatar.jpg` своим квадратным изображением (512×512).
3. **Цвета** — все оттенки и фоны вынесены в CSS-переменные в начале
   `css/style.css` (`--brand`, `--brand-2`, `--brand-3`, палитры тем).
4. **Шаринг** — заголовок и текст задаются в объекте `shareData` в `js/app.js`.
5. **Фразы печатной машинки** — массив `roles` в `js/app.js`.

## Совместимость

Chrome/Edge 111+, Firefox 113+, Safari 16.4+ — за счёт `color-mix()`, `inert` и
`backdrop-filter` (для старых браузеров есть `@supports`-фолбэки). Без JavaScript
карточка остаётся читаемой: видны все три раздела и заполненные полосы навыков.
